Privacy Policy

Last updated: 16 November 2026

This policy covers the Ancient Tech Daily website and shorts-factory, a private tool the channel owner runs on their own computer to publish videos to the Ancient Tech Daily YouTube channel.

Who uses shorts-factory

shorts-factory is used only by the owner of the Ancient Tech Daily channel. It is not offered to the public and does not ask anyone else to sign in.

What Google data it uses

shorts-factory uses the YouTube API Services. It asks Google for one permission only: youtube.upload, which lets it upload videos (with their title, description and tags) to the owner's own channel. It does not read, store or share any other YouTube or Google account data: no contacts, email, watch history, comments or analytics.

The sign-in token Google issues is stored only on the owner's computer and is never sent anywhere except to Google's own servers when uploading.

By using shorts-factory's upload feature, the owner is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Limited use

shorts-factory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, not used for advertising and not transferred to anyone.

Revoking access

Access can be removed at any time from the Google Account security settings, under Third-party apps & services.

Visitors to this website

This website has no sign-in, no forms, no cookies, no analytics and no advertising. It is hosted on GitHub Pages, which may log visitors' IP addresses for security; see the GitHub Privacy Statement.

Viewers of the videos

We receive no personal data about people who watch the videos beyond the aggregate statistics YouTube shows to every channel owner.

Changes and contact

If this policy changes, the date above will change. Questions: please open an issue on the website's repository.
