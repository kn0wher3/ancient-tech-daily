# Ancient Tech Daily website

Public website for the Ancient Tech Daily YouTube channel: about page, privacy policy and terms.
Hosted free on GitHub Pages at https://kn0wher3.github.io/ancient-tech-daily/

This is a SEPARATE project from the video pipeline (`shorts-factory`, private). It must never contain keys, `.env`
files or anything from that project. The privacy policy is the one linked from the Google Cloud consent screen of
the `shorts-factory` OAuth app, so keep its URL stable: `/privacy.html`.

Plain static HTML + one CSS file. No build step, no tracking, no cookies.
